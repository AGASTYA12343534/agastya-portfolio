# 🚀 Agastya Portfolio

A modern, responsive, and interactive developer portfolio built with **Next.js**, showcasing my projects, technical skills, experience, and competitive programming journey.

🌐 **Live Demo:** https://agastya-portfolio-git-main-agastya-s-projects4.vercel.app/

---

## ✨ Features

- 🎨 Modern and responsive UI
- 🌙 Dark mode support
- ⚡ Built with Next.js 16 & React 19
- 🎭 Smooth animations with Framer Motion
- 📱 Mobile-first responsive design
- 💼 Experience timeline
- 📂 Featured projects showcase
- 🏆 Coding Profiles section
- 🛠 Skills & technologies
- ❓ FAQ section
- 📬 Contact section with social links

---

| Category | Technologies |

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/AGASTYA12343534/agastya-portfolio.git
```

### Navigate to the project

```bash
cd agastya-portfolio
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open:

```
http://localhost:4000
```
